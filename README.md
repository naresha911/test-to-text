# Exam OCR

Create a tool which will convert the uploaded images to text.

The images belong to a question paper or practise test. . The output should be rendered and downloadable as json so that it can be pushed to the supabase. The text can be mathematical equations or diagrams, for intelligence tests.  Create renderers for different types of questions - mcq, complehensive, assertions, fill in the blanks, true or false etc..

You have option to choose either https://github.com/topdu/openocr

or any other free tools. Ask me questions if you have any
